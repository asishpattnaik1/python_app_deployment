## 📈 Pattern Recognition Guide

Learn to recognize problem patterns:

### Pattern: Hash Map for Fast Lookup
**Problems:** Two Sum  
**When to use:** Need to find pairs, complements, or duplicates  
**Time:** O(n), Space: O(n)

### Pattern: Two Pointers
**Problems:** Valid Palindrome  
**When to use:** Sorted arrays, palindromes, pair finding  
**Time:** O(n), Space: O(1)

### Pattern: Pointer Manipulation
**Problems:** Reverse Linked List  
**When to use:** Linked list operations  
**Time:** O(n), Space: O(1)

### Pattern: Dynamic Programming
**Problems:** Maximum Subarray  
**When to use:** Optimization, counting, subproblems  
**Time:** Varies, often O(n) or O(n²)

### Pattern: BFS/DFS
**Problems:** Binary Tree Level Order Traversal  
**When to use:** Tree/graph traversal, shortest path  
**Time:** O(n), Space: O(n)
